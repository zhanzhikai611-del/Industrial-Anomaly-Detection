> # 基于机器学习的 CNC 工业生产数据异常预警系统
>
> ## 1. 项目简介
>
> 本项目是一套面向工业 4.0 的智能化预警系统，旨在解决 CNC 铣床加工过程中的刀具磨损检测问题。系统基于 **密歇根大学真实 CNC 数据集**，利用逻辑回归（Logistic Regression）模型实现 25 台设备的实时健康监测。
>
> ## 2. 核心功能
>
> - **SaaS 化极简看板**：提供全场 OEE、生产产出及设备状态分布的宏观监控。
> - **AI 故障预警**：实时计算每台设备的磨损概率，并根据风险值（Anomaly Score）进行自动排序。
> - **深度钻取诊断**：支持点击单台设备查看“主轴电流 vs 故障概率”的双轴时序波形图。
> - **传感黑匣子**：全量记录 25 台设备的高频传感流水（电流、功率、速度等），实现故障溯源。
>
> ## 3. 技术架构
>
> - **后端**: Python / Django
> - **前端**: Vanilla JS / ECharts / Bootstrap (SaaS Minimal Style)
> - **算法**: Logistic Regression (逻辑回归二分类)
> - **仿真**: 多线程实时数据流生成引擎
>
> ## 4. 启动指南
>
> ### 环境准备
>
> 1. 确保安装了 Python 3.8+。
> 2. 安装依赖：`pip install -r requirements.txt`。
>
> ### 运行步骤
>
> 请务必确保双进程同时运行：
>
> 1. **启动 Web 服务器**：
>
>    Bash
>
>    ```
>    python manage.py runserver
>    ```
>
> 2. **启动数据仿真引擎**：
>
>    Bash
>
>    ```
>    python simulate_real_cnc_data.py
>    ```
>
> *访问 http://127.0.0.1:8000 查看实时监控界面。*
