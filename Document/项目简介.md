# CNC 智能生产异常监控预警系统——项目说明书 (V3.4.6)

## 一、 项目背景与痛点分析

在现有的 CNC 生产流程中，运维管理主要依赖“故障驱动”模式，即设备停机后才进行响应。这种模式导致了三大核心问题：
1. **非计划停机成本高昂**：突发故障导致产线瘫痪，严重影响交付周期。
2. **损失链路不可见**：传统看板仅能看到“坏没坏”，无法感知设备性能的缓慢衰减（性能流失）。
3. **决策链路长**：从发现异常到技术员到场诊断，中间存在严重的数据孤岛，缺乏即时的专家级指导。

本项目的目标是构建一个**数字化监控与预测性维护平台**，通过“数据驱动”实现生产风险的提前感知与闭环处理。

---

## 二、 系统架构与功能实现 (核心亮点)

项目已演进至 **V3.4.x** 版本，形成了以“Redis 高性能缓存-3D 数字孪生-双模态 AI 决策”为核心的工业 4.0 解决方案。

### 1. 3D 环境感知数字孪生 (3D Digital Twin - V3.2.0)
系统上线了单设备深度监控详情页，基于 **Three.js** 实现高保真 3D 模型渲染。
*   **交互特性**：支持 OrbitControls 自由视角、模型自适应缩放（CNC/LAT/TML 不同机型自动校准）。
*   **价值点**：实现“虚实结合”，管理人员足不出户即可通过 3D 视图直观感知设备的物理姿态与报警状态。

### 2. Redis 高性能缓存内核 (High-Performance Architecture - V3.3.0)
引入 Redis 作为状态快照层，彻底解除 MySQL 的实时查询压力。
*   **内存级响应**：设备矩阵状态获取延迟从 ~100ms 降至 **2ms 以内**。
*   **原子累加器**：今日产量等高频变动指标采用 Redis Atomic Counters，保障千万级数据下的看板秒开。

### 3. 工业级 AI 算法突破 (Algorithm Excellence - V3.4.0)
参考 IJSEM 2025 论文，通过深度特征工程压榨逻辑回归（LR）性能。
*   **多尺度时序建模**：引入 1min/5min 双窗口滑动特征，捕捉切削震颤信号。
*   **精确率飞跃**：Precision 从 23% 提升至 **35%+**，Recall 稳定在 **72%** 以上，极大降低了“虚惊一场”的误报困扰。
*   **价值点**：利用低算力模型实现接近深度学习的预警精度，支持边缘端极速推断。

### 4. 双模态 AI 智能体 (Agent Interoperability)
*   **Copilot（自动闭环）**：全时段扫描异常，自动执行安全停机并生成 AI 诊断报告，实现 24/7 无人值守。
*   **Ask（RAG 交互）**：接入 Qwen-max/Qwen-3.5，支持语义化查询：“哪些设备存在漏报风险？”或“查询 ID 252 的维护记录”。
*   **价值点**：打通数据孤岛，通过自然语言赋予管理人员专家级的诊断能力。
