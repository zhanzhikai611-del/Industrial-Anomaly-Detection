### V1.0.0 工业生产异常预警可视化系统 需求文档

#### 1. UI/UX 设计语言 (Modern SaaS 风格)

全面弃用深色背景与发光特效，转向经典的企业级后台（Admin Panel）设计规范。

- **整体布局**：经典的左右分栏结构。左侧为固定宽度侧边栏（Sidebar），右侧为内容展示区（Main Content）配合浅灰底色。
- **色彩规范**：
  - 全局背景：浅灰蓝 (`#f4f7fa` 或 `#f0f2f5`)。
  - 卡片背景：纯白 (`#ffffff`)，辅以极弱的灰色投影 (`box-shadow: 0 2px 12px 0 rgba(0,0,0,0.05)`)。
  - 品牌主色：沉稳的亮蓝色 (`#409EFF` 或 `#2b5cff`)，用于高亮当前菜单和主干进度条。
  - 警示配色：红色 (`#f56c6c`) 用于高风险与报警，绿色 (`#67c23a`) 用于正常运行，紫色/青色用于饼图分类区隔。
- **排版与字体**：加大留白，去边框化。字体使用系统默认黑体，颜色以深灰 (`#303133`) 为主。

#### 2. 全局导航架构 (多页面路由)

系统必须具备左侧常驻菜单，包含四个一级页面，点击后实现页面路由跳转。

| **菜单项 (Menu)**      | **路由 (Route)** | **页面定位**                                                 |
| ---------------------- | ---------------- | ------------------------------------------------------------ |
| **Dashboard (仪表盘)** | `/dashboard/`    | 默认首页，展示核心 KPI、全局图表与 Top 风险设备排行。        |
| **Device (设备列表)**  | `/devices/`      | 预警核心工作台，平铺展示全量设备卡片，并承载 AI 诊断子层弹窗。 |
| **Event (事件中心)**   | `/events/`       | 传感流水与报警日志的审计追溯大表。                           |
| **Setting (系统设置)** | `/settings/`     | 预警阈值调节与预测引擎启停控制。                             |

#### 3. 核心页面模块

##### 3.1 首页 Dashboard 

![image-20260225152606000](/Users/chanchihkai/Library/Application Support/typora-user-images/image-20260225152606000.png)

- **综合效能指标卡 (OEE)**：顶部横向主进度条展示综合 OEE，下方三个半圆弧仪表盘分别展示良率 (Q)、性能 (P)、可用性 (A)。数据来源于 `production_sensor_data` 的实时计算。
- **实时生产快报**：展示当日总产出和未处理报警
- **设备状态**：纵向列表展示当前设备总数，以及运行 (绿)、待机 (蓝)、停机 (红) 的具体台数。
- **系统异常报警（含两个子模块）**：
  1. 质量预测预警：双轴时序折线图 (Dual-Axis Line Chart) —— 展示“预警证据”。**左轴**：实时主轴电流（`spindle_current`）波形。**右轴**：模型预测的异常得分（`anomaly_score`）曲线。
  2. 异常指标异常分布：纯色大区块饼图，右侧附带图例与具体报报警次数主轴过流物理报警、主轴过载报警、震动激增。
- **设备风险排名 (Top 5)**：极简文字列表，展示排名、设备名称、设备型号、实时风险百分比。强制按照 AI 推断的异常概率降序排列。

##### 3.2 设备页 Device (`/devices/`)

![image-20260225155636867](/Users/chanchihkai/Library/Application Support/typora-user-images/image-20260225155636867.png)

- **设备状态展示栏**：顶部提供快速筛选按钮（全部设备、高风险吗（高于75%）、中风险（45-75%）、低风险（低于455））。

- **设备卡片矩阵**：展示 `device_info` 表中的物理资产列表。卡片需包含设备名、当前工序、以及直观的异常概率进度条。

  ![image-20260225155703880](/Users/chanchihkai/Library/Application Support/typora-user-images/image-20260225155703880.png)

- **AI 诊断详情 (弹窗)**：点击设备选项后弹出的纯白底色 Modal。包含下列内容

  1. **主轴电流 vs 故障概率**的 ECharts 折线图，去发光效果，使用细实线绘制，用于专业溯源。
  2. 当前关键特征值快照

##### 3.3 事件页 Event (`/events/`)

- **数据表格 (Data Table)**：经典的后台表格组件形式。展示 `production_sensor_data` 和 `anomaly_alert_log` 的时间戳、设备、报警类型、电流、功率、速度。带有分页器 (Pagination)。
