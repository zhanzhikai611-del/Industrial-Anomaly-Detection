# 工业生产数据异常预警系统 —— 前端架构与交互设计深度解析 (V3.5.0)

## 1. 技术栈选择：超媒体驱动 (HDA) 架构
本项目采用了现代化的 **超媒体驱动 (Hypermedia-Driven)** 架构，核心理念是“让服务器驱动交互”，避免了传统 JSON SPA (如 React/Vue) 带来的高开发成本和冗余的状态管理。

### 1.1 核心全家桶
*   **HTMX**: 负责 **局部刷新与异步交互**。通过 `hx-get`、`hx-post` 等属性，直接从后端获取 HTML 碎片并替换页面局部内容，实现无刷新导航。
*   **Alpine.js**: 负责 **客户端轻量状态管理**。处理如弹窗开关、菜单折叠、前端数据过滤等简单交互逻辑，语法类似于 Vue 但更轻量。
*   **ECharts**: 负责 **工业时序数据可视化**。渲染主轴电流、功率、异常风险分的动态实时曲线。
*   **Three.js**: 负责 **数字孪生 (Digital Twin)** 展示。在详情页加载 CNC 机床的 3D 模型，实现物理状态的视觉穿透。
*   **Vanilla CSS**: 使用 CSS 变量 (`variables.css`) 实现深色/浅色模式适配，追求极致的加载速度和设计灵活性。

## 2. 核心交互逻辑与实现

### 2.1 路由与请求封装 (SPA 体验)
系统虽然是多页面结构，但通过 HTMX 实现了 **SPA (单页应用) 体验**：
*   **主挂载点**: 在 `base.html` 中定义了 `#main-content` 区域。
*   **路由驱动**: 所有侧边栏链接都带有 `hx-get` 和 `hx-target="#main-content"`。
*   **URL 同步**: 使用 `hx-push-url="true"` 确保浏览器地址栏随导航更新，支持前进/后退。
*   **响应内容**: 后端视图通过判断请求头，如果是 HTMX 请求，则只返回页面主体（不含导航栏），从而实现极速切换。

### 2.2 Alpine.js 客户端状态机
系统使用 **Alpine.js** 作为轻量级粘合剂，管理复杂的客户端交互：
*   **组件初始化**: 每个主页面通过 `x-data x-init="DashboardApp.ui.init()"` 触发 JS 引擎。
*   **全局状态控制**: 负责控制 AI Agent 控制台的展开/折叠、弹窗的显示以及全局热键（如 ESC 退出）。
*   **HTMX 桥接**: 监听 `htmx:afterSettle` 事件，确保局部刷新后，新插入的 DOM 元素能被 Alpine 正确绑定。

## 3. 可视化引擎与渲染逻辑 (`dashboard.js`)

### 3.1 ECharts 响应式与轮询策略
*   **Polling (轮询)**: 函数 `pollAll` 采用 `AbortController` 机制，确保旧的请求在 5 秒周期到达前被取消，防止数据堆叠。
*   **ResizeObserver**: 系统对所有 ECharts 容器挂载了 `ResizeObserver`。当侧边栏收缩导致容器大小变化时，自动触发 `chart.resize()`，确保护目镜式的大屏体验。
*   **数据平滑渲染**: 时序折线图（`chart-line`）维护了 `tsArr`, `curArr`, `probArr` 三个内存数组，采用 `shift()` 逻辑维持 60 个采样点的滑动展示。

### 3.2 蜂窝拓扑 (Honeycomb) 引擎
系统使用 **原生 SVG** 渲染 25 台设备的拓扑矩阵。
*   **几何计算**: 函数 `hexPoints(cx, cy, r)` 动态计算六边形的顶点坐标。
*   **状态映射**: 根据从 `fetchMatrix` 获取的 `anomaly_score` 动态调整六边形的 `stroke` 颜色和动画类（如 `poly-high` 的呼吸灯效果）。
*   **交互穿透**: 点击六边形节点会触发 `htmx.ajax` 请求，直接在主内容区载入该设备的详细诊断页面。

## 4. 实时通信：WebSocket 与 AI 控制台
*   **Copilot 控制台**: 通过 `ws/copilot/` 与后端 `AgentService` 通信。
*   **日志染色**: 函数 `appendTerminalLog` 实时解析 WebSocket 消息中的标签（如 `[Action]`, `[AI]`），并根据 `labelColors` 字典进行前端着色，模拟极客化的控制台体验。
*   **Marked 集成**: AI Agent 的回复支持 Markdown 渲染，使诊断建议中的列表、粗体等格式得以完美呈现。

---

## 5. CSS 架构与视觉规范
系统采用了 **三层 CSS 体系** 确保设计的一致性：
1.  **`variables.css`**: 定义全局 HSL 颜色令牌、阴影等级和间距标准。
2.  **`layout.css`**: 负责基于 Grid 的响应式分栏布局。
3.  **`components.css`**: 封装了如报警指示灯、卡片玻璃态效果、以及各色状态类（`color-high`, `color-med`）。

## 6. 高级前端特性实现 (V3.5.0 专项)

### 6.1 数字孪生 (Digital Twin) 渲染管线
系统在详情页通过 `Three.js` 实现了高保真的 3D 监控：
*   **资产加载**：采用 `GLTFLoader` 加载 1:1 CNC 模型，通过 `DRACOLoader` 进行几何体压缩，确保在低带宽工业网络下也能秒级开启。
*   **实时驱动**：模型不仅是静态展示，其主轴旋转速度和刀库状态会根据 `current_status` 和实时传感数据进行动态插值动画渲染。
*   **视觉穿透**：利用 `MeshStandardMaterial` 的透明度属性，实现“透视”效果，将内部传感器位置与实时数据标签（Sprite）直接关联。

### 6.2 前端并发与压力控制 (Concurrency Control)
由于工业数据每 3 秒刷新一次，前端实施了严格的性能保护：
*   **请求原子化**：所有 HTMX 请求均挂载 `AbortController`，在发起新请求前自动终止未完成的陈旧请求，杜绝“竞态效应”。
*   **ECharts 降采样**：前端图表仅保留最近 60 个采样点，并通过 `notMerge: true` 选项执行增量更新，避免全量重绘导致的浏览器卡顿。

### 6.3 基于自定义事件的组件间通信
HTMX 与 Alpine.js 通过浏览器原生事件机制实现了“解耦通讯”：
*   **状态同步**：当 HTMX 完成局部刷新后，触发 `htmx:afterSettle` 事件，由 Alpine.js 的全局 `x-on` 监听器重新触发 `resize` 或 `re-init` 逻辑。
*   **动态提示**：后端通过 `HX-Trigger` 头下发自定义事件（如 `triggerAlert`），前端 Alpine.js 接收后立即弹出 Toast 提示框，无需前端编写复杂的定时检查逻辑。

### 6.4 响应式与视觉交互规范
*   **Glassmorphism (玻璃态)**：UI 大量采用 `backdrop-filter: blur()`，在保持工业严谨性的同时提升视觉层级。
*   **动态颜色令牌**：CSS 变量会根据 `anomaly_score` 的梯度（0.0-1.0）在运行时动态计算 HSL 值的饱和度与亮度，实现预警色的细腻平滑过渡。
