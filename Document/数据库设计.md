# 数据库设计

## 一、 数据源声明与设计思路

本系统的核心传感数据结构参考自公开的真实工业数据集：**密歇根大学系统级制造与自动化研究测试平台 (University of Michigan Smart Manufacturing Systems and Automation Research Testbed) 发布的 CNC 铣床刀具磨损数据集**（[数据来源：Kaggle - Tool Wear Detection in CNC Mill](https://www.kaggle.com/datasets/shasun/tool-wear-detection-in-cnc-mill)）。

针对“基于机器学习的工业生产数据异常预警系统”的课题需求，本数据库设计在保留了真实数据集核心高频电控参数（如主轴电流、输出功率）作为机器学习特征输入的同时，自主拓展了面向实际工业管理的业务字段（如负荷时间、停机时间、标准产能等），从而实现**AI 底层异常预警**与**顶层 OEE（全局设备效率）监控**的业务闭环。

## 二、 核心数据表结构字典

### 表 1：设备基础信息表 (`device_info`)

**设计说明**：用于集中管理车间内的物理资产。存放不随生产周期频繁变动的静态指标，是计算 OEE “性能稼动率” 的基准来源。

| **字段名称**        | **数据类型** | **约束条件**   | **用途与业务说明**                                           |
| ------------------- | ------------ | -------------- | ------------------------------------------------------------ |
| `id`                | Integer      | Primary Key    | **设备唯一标识 (Device ID)**。                               |
| `device_name`       | Varchar(50)  | Not Null       | **设备名称**。如“CNC-高光机-001”，用于前端列表展示。         |
| `device_type`       | Varchar(50)  | Nullable       | **设备型号**。区分不同加工精度的机床。                       |
| `standard_capacity` | Integer      | Not Null       | **标准产能 (Standard Capacity)**。单位时间内的理论最大产出数，用于计算 OEE 的性能稼动率。 |
| `current_status`    | Varchar(20)  | Default 'Running' | **当前运行状态**。枚举值：Running（运行）、Idle（待机）、Down（停机）。 |
| `current_group_id`  | Integer      | Default 1      | **生命周期分组 (V1.1 新增)**。通过 1-5 划分崭新至老旧设备，用以调控传感器底噪与异常发生概率。 |
| `yield_buffer`      | Float        | Default 0.0    | **脉冲产量累加器 (V1.4 新增)**。存放秒级轮询时尚未组成 1 个整件的小数份额，积满 1.0 时释放出物理产量。 |
| `defect_buffer`     | Float        | Default 0.0    | **次品脉冲累加器 (V1.4 新增)**。同上，管理高危设备良率折损。 |
| `maintenance_advice` | Text        | Default '...' | **维修建议/工单说明 (V2.2.0 新增)**。记录从监控页下发的人工工单。 |

### 表 2：生产与传感综合流水表 (`production_sensor_data`)

**设计说明**：系统的核心业务表，记录每个时间周期内的综合数据。本表融合了 Kaggle 数据集中的真实传感器特征与宏观生产管理指标，是逻辑回归（Logistic Regression）模型提取特征（$X$）和标签（$Y$）的唯一来源。

| **字段名称**            | **数据类型** | **对应 Kaggle 数据集字段**        | **用途与业务说明**                                           |
| ----------------------- | ------------ | --------------------------------- | ------------------------------------------------------------ |
| `id`                    | Integer      | -                                 | 流水记录的唯一标识。                                         |
| `device_id`             | Integer      | -                                 | 外键，关联 `device_info.id`，标识数据来源设备。              |
| `timestamp`             | Datetime     | -                                 | **数据采集时间**。用于 ECharts 渲染时序波形图。              |
| **`spindle_current`**   | Float        | `S1_CurrentFeedback`              | **主轴反馈电流**。逻辑回归模型核心特征 $X_1$。刀具磨损会导致切削阻力增大，主轴电流异常升高。 |
| **`spindle_power`**     | Float        | `S1_OutputPower`                  | **主轴输出功率**。逻辑回归模型核心特征 $X_2$。               |
| **`feed_velocity`**     | Float        | `X1_ActualVelocity`               | **X轴实际进给速度**。反映切削过程的动态稳定性，模型特征 $X_3$。 |
| **`machining_process`** | Varchar(50)  | `Machining_Process`               | **加工阶段**。如 "Prep" (准备), "Layer 1 Up" (切削)。用于模型数据清洗，剔除空转期干扰。 |
| `loading_time`          | Float        | -                                 | **负荷时间 (分钟)**。设备计划运行时间，用于计算 OEE 时间稼动率。 |
| `downtime`              | Float        | -                                 | **停机时间 (分钟)**。因异常停止运行时间，用于计算 OEE 时间稼动率。 |
| `input_qty`             | Integer      | -                                 | **投入数量**。该周期内投入生产的物料总数。                   |
| `actual_output`         | Integer      | -                                 | **实际产量**。用于大屏看板展示及计算 OEE 性能稼动率。        |
| `anomaly_score`         | Float        | -                                 | **异常风险分 (V3.4.6 新增)**。持久化存放模型推断概率值。     |
| **`tool_condition`**    | Boolean      | `tool_condition` (来自 train.csv) | **刀具磨损状态标签 ($Y$)**。0 代表正常，1 代表已磨损。       |

### 表 3：异常预警记录表 (`anomaly_alert_log`)

**设计说明**：记录系统产生的各类异常报警，支撑系统的闭环管理机制，并为大屏端的“异常分布监控”提供基础数据。

| **字段名称**    | **数据类型** | **约束条件**  | **用途与业务说明**                                           |
| --------------- | ------------ | ------------- | ------------------------------------------------------------ |
| `id`            | Integer      | Primary Key   | 报警日志唯一标识。                                           |
| `record_id`     | Integer      | Foreign Key   | 关联 `production_sensor_data.id`，用于在弹窗中追溯触发报警时的具体电流、功率等现场数据。 |
| `alert_time`    | Datetime     | Not Null      | **预警触发时间**。                                           |
| `alert_type`    | Varchar(50)  | Not Null      | **报警类型**。区分来源：如“LR模型刀具磨损预警”、“主轴过载物理报警”、“停机超时报警”。 |
| `anomaly_score` | Float        | Nullable      | **异常置信度得分**。记录逻辑回归模型输出的“刀具磨损概率”（0~1之间），为预警提供置信度依据。 |
| `is_handled`    | Boolean      | Default False | **处理状态**。0 表示未处理，1 表示已处理。用于实现工业生产中异常响应的闭环。 |

## 四、 Redis 高性能内存存储设计 (V3.3.0)

针对工业场景的高频 IO 特性，系统引入了 Redis 内存数据库，承担由于实时性要求极高、且无需永久保留的中间状态数据。

| **Redis Key** | **数据结构** | **生命周期** | **业务说明/用途** |
| --- | --- | --- | --- |
| `stats:output:today` | **String (Counter)** | 24 小时（天更）| **今日累计产量计数器**：仿真引擎每成功产出一件，执行 `INCR`。看板查询生产进度时直接读取此值。 |
| `device:status:all` | **Hash Map** | 永久 | **全厂设备实时快照图**：Field 为 `device_id`，Value 为 JSON 字符串（包含最新传感值、AI 分数与当前状态）。 |
| `stats:dashboard:overview` | **String (Cache)** | 60 秒 | **看板统计缓存**：存储 `get_dashboard_stats` 的聚合计算结果。避免高频刷新导致的复杂 SQL 重复执行。 |

## 五、 数据字典与核心业务逻辑映射说明

### 1. 机器学习预警机制的数据流转 (基于 Kaggle 数据)

- **特征工程 ($X$)**：系统通过 Pandas 提取 `production_sensor_data` 表中 `machining_process`（加工阶段）处于切削状态（如 "Layer 1 Up"）的数据。将 `spindle_current`（主轴电流）和 `spindle_power`（主轴功率）进行标准化处理作为模型输入特征。
- **监督学习标签 ($Y$)**：以 Kaggle 数据集提供的 `tool_condition`（刀具是否磨损）作为真实标签进行二分类逻辑回归 (Logistic Regression) 模型训练。
- **异常触发**：对实时接入的传感器数据进行推断。若模型输出的 `anomaly_score`（失效概率）超过 0.7，系统在 `anomaly_alert_log` 表中自动插入新记录，并在前端大屏触发“刀具磨损异常预警”。

### 2. OEE (全局设备效率) 实时计算机制（V1.1 级联重构）

系统后端不再使用静态的理想 OEE，而是基于各设备组态健康度进行真实级联扣减，并推送到前端 ECharts 看板：

- **时间稼动率 A** = `(loading_time - downtime) / loading_time`
- **性能稼动率 P** = `actual_output / 理论产量`
  *(其中理论产量 = 实际运行时间对应的标准产能份额 `(loading_time - downtime)/60 * standard_capacity`)*
- **质量合格率 Q** = `actual_output / input_qty`
  *(基于 V5 yield/defect_buffer 扣减后的实际良品出件率)*
- **全厂综合 OEE** = `A × P × Q`（严格连乘计算各阶段折损率）
