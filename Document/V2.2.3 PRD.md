### V2.2.3 产品需求文档 (PRD) — 前端架构解耦与模块化专项

**状态**：正式版 (Released) / 架构重构
**版本**：V2.2.3 (Decoupled Engine Edition)
**更新日期**：2026-03-14

---

#### 1. 背景与核心痛点 (Problem Statement)
随着系统功能（看板、3D工厂、维护中心等）的快速叠加，原有的 **Django 耦合式前端** 开发模式已达到维护瓶颈。
*   **资源碎片化**：大量 JavaScript 和 CSS 散落在 HTML 模板或 `includes` 文件中，导致代码极其难以追踪。
*   **耦合度过高**：前端表现逻辑与后端模板语法深度绑定，无法进行独立的单元测试或现代框架平滑迁移。
*   **性能隐患**：重复加载的不规则内联资源块增加了首屏解析压力。

#### 2. 架构重构目标 (Objectives)
执行 **“Phase 2 - 物理资产剥离 (Physical Asset Decoupling)”** 计划，将系统进化为准单页应用架构。
*   **资源闭环化**：所有页面拥有独立的 CSS 样式表和 JS 逻辑引擎。
*   **引擎化封装**：引入命名空间模式（App Engine Pattern），将页面逻辑封装在独立的 JS 对象中。
*   **模板纯净化**：HTML 模板回归其本质作用——仅作为 DOM 骨架。

#### 3. 核心重构设计 (Redesign Specifications)

##### 3.1 物理资源矩阵 (Asset Matrix)
新版本建立了严格的 `static` 目录规范，所有页面资源均按功能引擎归类：
*   **CSS 层 (`/static/monitor/css/`)**:
    *   `dashboard.css`, `device.css`, `account.css`, `event.css`, `setting.css`, `factory.css`, `login.css`
*   **JS 层 (`/static/monitor/js/engines/`)**:
    *   各页面对应的 `*.js` 逻辑引擎。

##### 3.2 引擎封装规范 (Engine Encapsulation)
放弃传统的全局函数，统一采用 **Namespace Object** 模式，以 `DashboardApp`, `DeviceApp`, `AccountApp` 等为核心：
*   **State Management**: 每个引擎拥有专属的 `state` 对象，记录当前选中的设备 ID、筛选状态、图表实例等。
*   **Lifecycle UI**: 包含统一的 `init()` 入口、弹窗控制 `ui` 模块。
*   **Data Bootstrapping**: 采用轻量化数据注入，Django 仅负责将初始 JSON 状态 (`safe` filter) 常驻在 HTML 指标区，由外部 JS 引擎接手渲染。

##### 3.3 专项优化细节
*   **3D 工厂引擎 (`factory.js`)**: 成功剥离 600+ 行 Three.js 繁杂代码，实现了场景初始化、补间动画与 WebSocket 逻辑的高内聚封装。
*   **设备监控分析 (`device.js`)**: 统一了数据轮询机制与 AI 诊断模态框的动态交互逻辑。
*   **统一设计令牌 (Sync Tokens)**: 所有 CSS 均通过继承 `base.html` 中定义的 CSS Variables（如 `--primary`, `--font-mono`），确保了全系统视觉风格的一致性。

#### 4. 技术栈改动
*   **静态资源管理**: 引入 Django `staticfiles` 完整标准流。
*   **封装模式**: JavaScript Module Pattern (IIFE/Simplified Namespace).
*   **UI 组件**: 完善了基于 `CSS Grid` 和 `Flexbox` 的响应式布局剥离。

#### 5. 迁移安全性
*   **CSRF 安全守卫**: 将 Django CSRF Token 获取逻辑集成至各 JS 引擎。
*   **清理冗余**: 彻底删除了 `/templates/monitor/includes/` 目录下大量过时的 `.html` 格式的脚本包含块。

#### 6. 架构示意图 (Architecture & Refactoring Summary)

| 页面名称 | 剥离 JS 引擎 | 剥离内容简述 | 
| :--- | :--- | :--- |
| **控制面板** | `dashboard.js` | 蜂窝图渲染、图表初始化、实时报警 |
| **设备列表** | `device.js` | 设备过滤、排序、AI诊断、故障申报 |
| **账号管理** | `account.js` | CRUD 操作、密码可见性切换、分页 |
| **事件中心** | `event.js` | ECharts 趋势图、统计图、事件搜索 |
| **系统设置** | `setting.js` | 实时流控制、统计重置、阈值配置 |
| **3D 工厂** | `factory.js` | Three.js 场景管理、孪生体同步、日志流 |

> **注**：V2.2.3 标志着项目正式完成前端物理资产的正规化。未来的 V3.0 将在此基础上推进先行路由注入与逻辑虚拟化。
