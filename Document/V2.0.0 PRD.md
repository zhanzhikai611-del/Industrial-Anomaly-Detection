### V2.0.0 PRD 预研文档：智能 Agent 自主治理 (Autonomous Agent)

- **迭代目标**：实现“无人值守”的预测性维护，由 AI Agent 代替人工进行决策。
- **功能核心：Agent 接管模式**
  - **自动感知**：Agent 实时监控 `Device` 表的风险得分趋势。
  - **自动决策**：
    - 若 `Risk > 85%` 持续 10 秒 -> 下发 `Stopped` 指令。
    - 若 `Risk` 处于中风险且 OEE 严重下滑 -> 尝试将设备切换至 `Standby`。
  - **自动修复**：Agent 自动触发 V1.0.3 的“处理”动作（模拟 AI 自动完成微调或通知维修）。
- **可视化**：新增“Agent 思考轨迹”控制台，展示 AI 的分析过程。

###  V2.0.0 Agent 模式的交互痛点

- **挑战**：Agent 自动改状态可能会让用户感到“莫名其妙”。
- **解决方案**：引入一个 **“控制权切换按钮”**。
  - **Manual 模式**：用户手动点击。
  - **Agent 模式**：所有操作置灰，Agent 自动操作，并伴有强烈的视觉反馈（如界面边缘发光）。
