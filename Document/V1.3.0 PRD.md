> **版本状态**：设计中

> **核心目标**：构建完整的用户鉴权体系（Login/Logout），完善基于角色的权限控制（RBAC）

#### 1. 新增功能：身份认证模块 (Authentication)

##### 1.1 登录界面 (Login Page)

- **设计风格**：延续 **CNC Cloud** 纯白 SaaS 风格，保持简洁、专业。
- **核心元素**：
  - **背景**：浅灰色 (#f4f7fa) 背景，中心为纯白圆角登录卡片。
  - **品牌展示**：卡片顶部显示项目 Logo 与名称。
  - **表单项**：工号/用户名输入框、密码输入框（明文/密文切换）。
  - **状态反馈**：登录失败时，输入框下方出现红色错误提示。

##### 1.2 登出逻辑 (Logout)

- **交互入口**：顶部 Header 右侧用户头像下拉菜单，新增“安全退出”选项。
- **业务逻辑**：清除 Django Session，强制跳转回登录页。

##### 2.1 账号字段规范

系统需展示并支持以下字段的 CRUD 操作：

| **字段名**   | **类型** | **说明**                                        |
| ------------ | -------- | ----------------------------------------------- |
| **用户名**   | Char     | 系统登录唯一标识                                |
| **真实姓名** | Char     | 用于显示及报表记录                              |
| **工号**     | Char     | 工业场景唯一识别码                              |
| **所属角色** | Enum     | 决定系统操作权限（Admin / Engineer / Operator） |
| **创建时间** | DateTime | 账号初始化时间                                  |
| **账号状态** | Boolean  | 启用（正常） / 禁用（锁定）                     |
| **操作**     | UI       | 编辑、重置密码、权限变更                        |

##### 2.3 賬號創建彈窗 (Add Account Modal)

![image-20260227225117801](/Users/chanchihkai/Documents/基于机器学习的工业生产数据异常预警系统/Document/assets/image-20260227225117801.png)

為了確保賬號創建過程的規範化與安全性，系統需提供一個引導式的彈窗介面。

#### 視覺與交互設計

- **彈窗佈局**：純白背景圓角彈窗，頂部帶有藍色用戶圖標與「新增賬號」標題。
- **引導文字**：副標題為「創建新的系統賬號並分配角色」。
- **欄位樣式**：兩列佈局，帶有佔位符提示（Placeholder），必填項標註紅色星號（*）。

#### 欄位定義與校驗規範

| **欄位名稱** | **輸入類型** | **校驗/提示規範**                                    |
| ------------ | ------------ | ---------------------------------------------------- |
| **用戶名**   | 文本框       | 必填，提示：e.g. jeremy_09                           |
| **真實姓名** | 文本框       | 必填，提示：e.g. 張偉                                |
| **工號**     | 文本框       | 必填，提示：# 6位數字                                |
| **初始密碼** | 密碼框       | 必填，提示：至少6位，支持明文/密文切換查看           |
| **所屬角色** | 下拉菜單     | 必填，提供「系統管理員」、「工程師」、「操作員」選項 |

#### 底部操作欄

- **取消按鈕**：灰色文字按鈕，點擊關閉彈窗。
- **確認創建**：藍色高亮按鈕，帶有用戶新增圖標。點擊後執行後端 `UserProfile` 創建事務。

#### 3.  技术实施建议

- **前端**：使用 Django 模板配合 Bootstrap 5 的 `.form-control` 实现登录页，Icon 建议使用 **Bootstrap Icons** 的 `send` 或 `envelope` 图标。
- **后端**：利用 Django 内置的 `auth` 模块结合 `UserProfile` 扩展模型进行角色判定。
