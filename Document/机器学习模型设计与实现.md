## 3.1 算法选型与数学原理

### 3.1.1 选用逻辑回归的依据

本系统选用**逻辑回归（Logistic Regression）**作为刀具磨损预警的核心分类算法，理由如下：

**① 问题本质是二分类问题**

刀具状态仅有两种：正常（Unworn，$Y=0$）和磨损（Worn，$Y=1$）。逻辑回归天然适配此类二分类场景，输出的概率值（$0 \sim 1$）可直接映射为"刀具磨损置信度"，对工业现场人员具有直觉上的可解释性。

**② 数学原理：Sigmoid 函数与最大似然估计**

逻辑回归在线性回归的基础上，引入 **Sigmoid 激活函数**将连续实数域映射到概率区间 $[0, 1]$：

$$P(Y=1 \mid \mathbf{x}) = \sigma(\mathbf{w}^T \mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{x} + b)}}$$

其中：
- $\mathbf{x} = [x_1, x_2, \ldots, x_d]^T$ 为特征向量（主轴电流均值/最大值/标准差等）
- $\mathbf{w}$ 为待学习的权重向量，$b$ 为偏置项
- $\sigma(\cdot)$ 为 Sigmoid 函数：$\sigma(z) = \dfrac{1}{1+e^{-z}}$

模型通过最小化**加权交叉熵损失**（结合 L2 正则化）求解最优参数 $\mathbf{w}^*$：

$$\mathcal{L}(\mathbf{w}) = -\frac{1}{n}\sum_{i=1}^{n} w_i \left[ y_i \log \hat{p}_i + (1-y_i)\log(1-\hat{p}_i) \right] + \frac{\lambda}{2}\|\mathbf{w}\|_2^2$$

其中 $w_i$ 为样本级别权重（由 `class_weight='balanced'` 控制），$\lambda = 1/C$ 为正则化系数。

决策边界设定为概率阈值 $\tau = 0.7$（磨损置信度超过 0.7 触发预警），避免使用默认的 0.5 导致漏报。

**③ 工业边缘计算的低算力优势**

相较于支持向量机（SVM）、随机森林（Random Forest）和深度神经网络（DNN），逻辑回归具有以下工程优势：

| 指标 | 逻辑回归 | 随机森林 | 深度神经网络 |
|------|---------|---------|------------|
| 模型大小 | < 10 KB | 数 MB | 数十 MB |
| 单次推断时间 | < 1 ms | 数 ms | 数十 ms |
| 训练数据需求 | 百 ~ 千级 | 千 ~ 万级 | 万 ~ 百万级 |
| 可解释性 | ✅ 高（系数即重要性）| ⚠️ 中 | ❌ 低（黑盒）|
| 适合边缘部署 | ✅ | ⚠️ | ❌ |

在工业设备边缘节点（如 PLC、工控机）上，受限于 CPU 算力和内存，逻辑回归的**毫秒级推断延迟**和**KB 级模型体积**具有决定性的部署优势。

## 3.2 基于真实工业数据集的特征工程优化

### 3.2.1 数据清洗：过滤非切削工序（State Filtering）

CNC 铣床的工作周期包含多个阶段：准备（Prep）、切削（Layer Up/Down）、重定位（Repositioning）和结束（End）。在 Prep 和 End 阶段，主轴处于**空转或低速状态**，电流、功率接近零基线，不反映刀具真实切削载荷。

若将此类噪声数据混入训练集，会严重拉低各特征均值，导致分类边界失效。

**工业物理学意义**：刀具磨损引起的变化（切削力增大→电流上升、振动加剧→进给速度标准差增大）只在**主轴实际切削材料**时才产生。因此，本系统仅保留 `Machining_Process` 包含 `'Layer'` 的记录（Layer 1 Up/Down、Layer 2 Up/Down、Layer 3 Up/Down），确保训练数据的物理有效性。

```python
# 剔除 Prep / Repositioning / End 空转阶段
NON_CUTTING_STAGES = {'Prep', 'Starting', 'End', 'Repositioning'}
df = df[~df['machining_process'].isin(NON_CUTTING_STAGES)]
```

### 3.2.2 特征降维：剔除共线性冗余特征（Drop Correlated Features）

在原始 CNC 数据集中，每个轴（X/Y/Z/Spindle）均包含"指令值（Command）"和"实际读数（Actual）"两类字段。**指令值**是数控系统的预设输入，仅反映加工程序设定，与刀具健康状态无关；**实际值**则反映了刀具受力后的真实物理响应，才是异常检测的有效特征。

引入指令特征会导致**多重共线性（Multicollinearity）**：指令值与实际值之间存在极高的线性相关性（通常 $r > 0.95$），违反逻辑回归的特征独立性假设，使权重估计不稳定。

本系统选用的三维核心特征均为实际读数：

| 特征 | Kaggle 原始字段 | 选用理由 |
|------|---------------|---------|
| `spindle_current` | `S1_CurrentFeedback` | 最直接反映刀具切削受力（磨损 → 切削阻力增大 → 电流上升） |
| `spindle_power` | `S1_OutputPower` | 综合功率，与电流高度互补，捕捉能量损耗异常 |
| `feed_velocity` | `X1_ActualVelocity` | 进给实际速度，磨损时切削颤振导致速度波动 |

### 3.2.3 时序特征聚合：滚动统计特征（Rolling Statistical Aggregation）

逻辑回归是**静态点分类器**，无法直接建模时间序列的动态演变规律。为了将时序信息注入逻辑回归，本系统引入**滑动时间窗口聚合**方法：

以每台设备为单位，对 5 分钟滚动窗口内的传感器数据计算以下三类统计量：

$$x_{mean} = \frac{1}{|W|}\sum_{t \in W} x_t, \quad x_{max} = \max_{t \in W} x_t, \quad x_{std} = \sqrt{\frac{1}{|W|}\sum_{t \in W}(x_t - x_{mean})^2}$$

三类统计量的工业物理意义如下：

| 统计量 | 工业物理含义 | 诊断价值 |
|--------|------------|---------|
| **均值** ($\mu$) | 该窗口内的平均载荷水平 | 反映持续性负载变化（磨损后均值系统性偏高）|
| **最大值** (max) | 窗口内的峰值冲击 | 捕捉刀具崩刃等突发性极端事件 |
| **标准差** ($\sigma$) | 信号波动剧烈程度 | **最敏感指标**：磨损导致切削不稳定，$\sigma$ 显著增大 |

> **关键洞察**：标准差（std）是最适合逻辑回归的刀具磨损特征。新刀具切削平稳，信号 $\sigma$ 小；磨损刀具因刃口不规则产生周期性切削颤振（Chatter），$\sigma$ 显著增大。此变化与磨损程度单调正相关，是理想的线性可分特征。

**三维特征 × 三种统计量 = 9 维特征矩阵 $X$**，大幅提升逻辑回归捕捉时序异常的能力。

### 3.2.4 特征标准化：StandardScaler 消除量纲差异

构建的 9 维特征矩阵存在严重的**量纲不一致**问题：

- `spindle_current` 量级：数十安培（A）
- `spindle_power` 量级：零点几瓦（W）
- `feed_velocity` 量级：数毫米/秒（mm/s）

逻辑回归通过梯度下降优化，若各特征值域差异悬殊，梯度会沿大量纲特征方向极度倾斜，导致收敛缓慢甚至参数失效。**StandardScaler** 将每个特征归一化为零均值、单位方差：

$$x'_j = \frac{x_j - \mu_j}{\sigma_j}, \quad j = 1, 2, \ldots, 9$$

标准化后各特征处于同等尺度，优化路径趋于各向同性，大幅加速 L-BFGS 求解器收敛。

> **工程注意**：StandardScaler 的均值 $\mu_j$ 和标准差 $\sigma_j$ **只能在训练集上 `fit`**，再用相同参数 `transform` 测试集，防止数据泄露（Data Leakage）。

## 3.3 应对样本不平衡（Class Imbalance）

### 3.3.1 工业场景的痛点

工业设备在正常运行周期内，**正常工况占绝大多数，异常事件极少发生**。在本系统的仿真数据中，磨损样本（worn=1）仅占约 15%，而在真实工厂中异常比例往往低至 1%~5%。

若直接用不平衡数据训练，模型会倾向于将所有样本预测为多数类（正常），以此获得高准确率：

$$\text{Accuracy} = \frac{N_{normal}}{N_{total}} \approx 95\%$$

然而，此时**所有异常样本均被漏报**，在工业安全场景中是完全不可接受的。

### 3.3.2 class_weight='balanced' 惩罚机制

本系统通过 sklearn 的 `class_weight='balanced'` 参数，自动为每个类别分配**反比于其频率的样本权重**：

$$w_c = \frac{N_{total}}{K \cdot N_c}$$

其中 $N_{total}$ 为总样本数，$K=2$ 为类别数，$N_c$ 为类别 $c$ 的样本数。

等效效果：**每个磨损样本（正类）在损失函数中的权重提升约 $N_0 / N_1$ 倍**，迫使模型同等重视稀缺的异常样本，避免简单地预测多数类。

```python
# 加权交叉熵，磨损样本权重自动提升 ~5.7倍（85%/15%）
model = LogisticRegression(
    class_weight='balanced',  # ← 关键参数
    max_iter=1000,
    C=1.0,       # L2 正则化，防止过拟合
    solver='lbfgs',
)
```

## 3.4 模型评估指标体系

### 3.4.1 混淆矩阵与四大指标定义

对于二分类预警模型，混淆矩阵定义如下：

|  | 预测：正常 (0) | 预测：磨损 (1) |
|--|--------------|--------------|
| **真实：正常 (0)** | TN（真負例）| FP（假正例，误报）|
| **真实：磨损 (1)** | FN（假负例，**漏报**）| TP（真正例）|

四大核心指标定义：

$$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$$

$$\text{Precision} = \frac{TP}{TP + FP} \quad \text{（预测为磨损中，真正磨损的比例）}$$

$$\text{Recall} = \frac{TP}{TP + FN} \quad \text{（真实磨损中，被成功预测到的比例）}$$

$$\text{F1-Score} = \frac{2 \times \text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} \quad \text{（精确率与召回率的调和均值）}$$

### 3.4.2 为何"召回率"是工业预警的核心指标

在工业预警场景中，两类错误的**代价严重不对称**：

| 错误类型 | 技术名称 | 工业后果 | 代价 |
|---------|---------|---------|------|
| 将磨损刀具误判为正常 | FN（**漏报**）| 磨损刀具继续切削 → 工件报废 → 刀具折断撞机 → 设备损毁 | **极高（不可接受）**|
| 将正常刀具误判为磨损 | FP（**误报**）| 系统发出预警 → 人工停机检查 → 虚惊一场 → 浪费检查时间 | **低（可接受）**|

因此，工业预警系统的首要优化目标是**最大化召回率（Recall）**，即确保磨损刀具被"一网打尽"：

$$\text{Recall} = \frac{TP}{TP + FN} \to \text{尽量接近 } 100\%$$

**宁可误报十次让人工复核，绝不漏报一次导致重大生产事故。**

> 工业实践建议：设定系统预警阈值 $\tau = 0.7$（模型输出磨损概率 > 70% 即触发预警），相比默认的 0.5，可在牺牲少量精确率的前提下显著提升召回率，更符合工业安全准则。

准确率（Accuracy）在类别不平衡场景下具有误导性（全预测为正常也能达到 95% 准确率），不应作为主要评估指标。F1-Score 在精确率与召回率之间取调和均值，是综合评估模型质量的良好选择，但工业预警场景中**Recall 始终优先**。

## 3.5 模型文件与部署

训练完成后，模型持久化为以下文件，供后续在线推断调用：

```
ml_models/
├── logistic_model.pkl    # 逻辑回归模型（权重矩阵 w 和偏置 b）
├── scaler.pkl            # StandardScaler（训练集的均值和标准差）
└── feature_names.pkl     # 9 维特征名称列表（推断时对齐顺序）
```

**在线推断调用示例**：

```python
import joblib
import numpy as np

model  = joblib.load('ml_models/logistic_model.pkl')
scaler = joblib.load('ml_models/scaler.pkl')

# 实时传感数据（9维聚合特征）
X_new = np.array([[current_mean, current_max, current_std,
                   power_mean,   power_max,   power_std,
                   velocity_mean,velocity_max,velocity_std]])

X_scaled   = scaler.transform(X_new)
prob_worn  = model.predict_proba(X_scaled)[0, 1]   # 刀具磨损概率

if prob_worn > 0.7:   # 召回率优先阈值
    trigger_alert('LR_TOOL_WEAR', anomaly_score=prob_worn)
```
